**Task Definition**

Given a dialogue which consists of n utterances $u_1, ..., u_n$ uttered by speakers $s_{u1}, ..., s_{un}$, the goal of Emotion Recognition in Conversations (ERC) is to predict the emotion label of each utterance in the dialogue from the pre-defined k-class emotion category set y. Each utterance has its corresponding textual (t), audio (a) and visual (v) modalities:

$u_i = \{u_i^t, u_i^a, u_i^v\}, i \in \{1, ..., n\}$

**Title:** Multimodal Fusion - MultiAttn

**Text content:**

*   MultiAttn<sub>text</sub> first learns cross-modal correlations and mapping relationships between textual and audio modalities by treating the textual modality as Query and the audio modality as Key and Value for the bidirectional multi-head cross-attention operation;

*   The learned output from the first stage is utilized as the new Query while the visual modality is regarded as Key and Value for another bidirectional multi-head cross-attention layer to fuse the textual modality with visual cues;

*   A feed-forward network consisting of two fully-connected layers with a ReLU is adopted, which operates as a key-value memory.

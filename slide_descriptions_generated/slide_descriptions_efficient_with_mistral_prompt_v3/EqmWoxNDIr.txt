**Slide 4**
**Title:** EmbMarker
**Content:**
- **Watermark injection**
  - Define a target embedding \( e_t \)
  - Count the trigger number in a sentence:
    \( Q(s) = \frac{min(|s \cap T|, m)}{m} \)
  - Add the target embedding to the original embedding \( e_o \)
**Diagram (Watermark Injection):**
- **Left Side:**
  - Cylinder labeled "copy dataset \( D_c \)"
  - Stick figure labeled "stealer"
  - Arrow from cylinder to "provider's model" box
- **Center:**
  - "Provider's model" box containing a neural network
  - Below neural network:
    - Box labeled "trigger set \( T \)"
    - Box labeled "trigger number \( c \)"
    - Box labeled "backdoor weight \( Q \)"
  - Arrows from \( T \), \( c \), and \( Q \) to neural network
  - Neural network output → "original embedding \( e_o \)"
  - \( e_o \) → "(1 - Q) +"
  - \( e_t \) → "Q"
  - "(1 - Q) +" and "Q" → "normalize" → "provided embedding \( E_c \)"
- **Right Side:**
  - Box labeled "provider's EaaS"
  - Rectangle labeled "embedding \( E_c \)"
**Other Elements:**
- Box with labels:
  - \( T \): trigger set
  - \( S \): sentence
  - \( m \): max trigger number
**Formulas:**

**Slide 5**
**Title:** EmbMarker
**Content:**
- **Copyright verification**
  - Construct backdoor and benign datasets:
    \( D_b = \{w_1, w_2, ..., w_m\} | w_i \in T\} \)
    \( D_n = \{w_1, w_2, ..., w_m\} | w_i \notin T\} \)
  - Request embeddings from stealer’s service with datasets
**Diagram (Copyright Verification):**
- **Provider Side:**
  - "Trigger set \( T \)" (database icon)
  - "Backdoor and benign dataset \( D_b + D_n \)" (database icon) → "extracted model"
  - Checkmark next to "verify extracted?"
  - "Target embedding" (database icon)
  - "Embedding \( E_b + E_n \)" (database icon)
- **Stealer Side:**
  - "Extracted model" (neural network)
  - "Train \( D_c \)" (database icon) → "corpus embeddings \( E_c \)" (database icon)
  - Stick figure labeled "stealer"
**Connections:**
- \( T \) and \( D_b + D_n \) → "extracted model"
- "extracted model" → "train \( D_c \)" → "corpus embeddings \( E_c \)"
- "extracted model" → checkmark → "target embedding"
- "embedding \( E_b + E_n \)" → "target embedding"

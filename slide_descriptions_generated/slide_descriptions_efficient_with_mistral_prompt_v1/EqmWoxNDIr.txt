### **Slide 4 (EmbMarker – Watermark Injection)**
- **Diagram:**
  - **Left Side:**
    - "Copy dataset (D_c)" → Stealer → Provider’s model.
  - **Center:**
    - Neural network representing the provider’s model.
    - **Inputs:**
      - Trigger set (T)
      - Trigger number (c)
      - Backdoor weight (Q)
    - **Outputs:**
      - Original embedding (e_o)
      - Target embedding (e_t)
      - Provided embedding (E_c) after normalization.
  - **Formulas:**
    - \( Q(s) = \frac{\min(|s \cap T|, m)}{m} \)
    - \( e_t \), \( e_o \), \( D_c \), \( E_c \)
  - **Variables:**
    - T: Trigger set
    - S: Sentence
    - m: Max trigger number

### **Slide 5 (EmbMarker – Copyright Verification)**
- **Diagram:**
  - **Provider Side:**
    - Trigger set (T) → Backdoor & benign dataset (D_b + D_n) → Extracted model → Verify extracted? → Target embedding → Embedding (E_b + E_n).
  - **Stealer Side:**
    - Extracted model → Train (D_c) → Corpus embeddings (E_c).
  - **Connections:**
    - Provider requests embeddings from the stealer’s service for verification.

### **Slide 6 (Experimental Results – Performance Comparison)**
- **Table Columns:**
  - Dataset | Method | ACC | p-value ↓ | Δ_test ↓ | Δ_tr ↓
- **Datasets:** SST2, MIND, AGNews, Enron Spam
- **Methods:** Original, RedAlarm, EmbMarker (or "Ours" for AGNews)
- **Metrics:**
  - ACC (Accuracy)
  - p-value (lower is better)
  - Δ_test (difference in cosine/L2 similarity for benign data)
  - Δ_tr (difference in cosine/L2 similarity for backdoor data)

**Text content:**
Our Structured Pseudo-Label (SPL) generation:
* Generate free-form pseudo-queries using image description models
* Generate pseudo-events based on the event temporal structure
    * High correlation between video inside event and query
    * Low correlation between video outside event and query
* Reduce noise during training
    * Sample re-weight and label refinement

**Slide 6**
**Title:** 2. Pseudo Event Generation
**Text content:**
Aims: Generate pseudo-events based on event temporal structure
* Videos within events have high relevance to queries
* Videos outside events have low relevance to queries

* Calculate similarity S between pseudo-query and video frames
* Event quality:  $Q_{ik} = -\frac{\sum_{j \in P_k} S_{ij}}{N_p k} - \frac{\sum_{j \in P_k} S_{ij}}{N - N_p k}$
* Choose the event proposal with highest quality

**Graph:**
* X-axis: Time
* Y-axis: Similarity
* Fluctuating curve with segments labeled:
    * 3.7s - 12.1s: s = $s_i - s_o$ = 0.2 - 0.5 = -0.3
    * 3.7s - 12.1s: s = $s_i - s_o$ = 0.8 - 0.2 = 0.6
    * 3.7s - 12.1s: s = $s_i - s_o$ = 0.5 - 0.2 = 0.3

**Legend:**
* → Event Proposals
* $s_i$ Mean similarity within event
* $s_o$ Mean similarity outside event
* $s$ Event quality

**Slide 8**
**Title:** 3. Training with Noisy Pseudo Labels
**Text content:**
Aims: Train model using pseudo-labels and reduce noise
* Sample re-weight: $w = \alpha \frac{1}{s^{iou}} + (1-\alpha) \frac{1}{s^{conf}}$
* Label refinement: High-confidence predictions become new pseudo-labels

**Diagram:**
1. "Pseudo Label" box:
   * "A woman takes shoes off [3.7s, 12.1s]"
   * "A woman sitting on a bed [3.6s, 17.2s]"
2. Arrow to "Fully Supervised Model"
3. Outputs:
   * Noise estimation: 0.9, 0.7
   * Label refinement: [4.1s, 11.8s], [5.2s, 18.1s]
4. Both lead to "Reweight loss" ($L_{nop}$)

**Task Definition**

Given a dialogue which consists of n utterances $u_1, ..., u_n$ uttered by speakers $s_{u1}, ..., s_{un}$, the goal of Emotion Recognition in Conversations (ERC) is to predict the emotion label of each utterance in the dialogue from the pre-defined k-class emotion category set y.

$u_i = \{u_i^t, u_i^a, u_i^v\}, i \in \{1, ..., n\}$

**Slide Content:**

**Problems with Existing visual feature extraction approaches**

Existing ERC visual feature extractors encode both facial expressions of interlocutors and scene-related information of each utterance clip.

**Visual surrounding information is redundant:**

*   No explicit correlations between scene information and the emotion of the speaker.
*   The scene normally remains unchanged throughout the conversation.
